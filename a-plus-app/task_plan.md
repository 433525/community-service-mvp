# 社区服务 MVP 实施计划

## 目标

先交付本地合成数据最小可用版，走通主要服务链：居民登记通用求助 → 工作台人工受理、初筛、转介与跟进 → 居民端查看本机演练进度。

## 边界

- 沿用现有 Vue 3、Vite、Vant 与两个独立入口。
- 仅使用虚构合成数据和浏览器本机存储。
- 不接真实居民、机构、短信/微信通知、紧急派单或真实履约。
- 本目录不是 Git 仓库，本轮跳过 Git 操作，不初始化仓库。

## 验收

- 开放和已被本机演练接单的社区求助均可被工作台人工导入；重复登记可见且不会重复创建。
- 工作台状态变化可在居民“服务记录”和“消息/服务进度”中按来源帖子查看。
- 工作台关联重开后居民端显示最新重开记录；重置社区种子数据后旧 A+ 状态不串到新帖子。
- 工作台存档损坏、版本不支持或读不到时，居民页面安全降级，不覆盖任一应用数据。
- 进度信息清楚标注为本机演练，不暗示真实通知、派单或履约；`npm run build` 通过。
