# B 评论审核本机实测（2026-10-21）

学校大创项目，项目负责人为用户本人。此次仅使用本地合成数据，在独立浏览器会话 `community-b-comments` 操作 `/community.html`，结束后已关闭会话。

## 操作结果

1. 成员在预置求助帖提交“B评论验收：虚构书架整理建议，仅合成数据。”，页面提示待审核；成员评论列表没有显示该正文，计数仍为 1。
2. 切换审核员，待审评论为 1。不填写审核理由点击通过，操作被阻止，队列仍为 1、日志为 0。
3. 填写“合成验收：内容为虚构建议，允许展示。”后通过，队列变为 0、日志为 1。
4. 返回成员社区，评论计数为 2，展开后能看到新评论正文。
5. 审核员填写“合成验收：演练下架评论。”并下架 `SYNTH-COMMENT-006`，日志为 2，包含通过和下架记录。
6. 返回成员社区并展开评论，计数恢复为 1，新评论正文不再展示。
