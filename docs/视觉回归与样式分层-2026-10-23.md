## 1. 参考项目与取舍

按“每个开发步骤先在 GitHub 找同类优秀项目”的要求，本轮三个步骤分别查阅了以下项目。**当仓库实现与官方文档冲突时以文档为准**；本轮未发现冲突，URL 语义按 MDN 的 History API 与 `popstate` 规范实现。

### 1.1 URL 查询状态：`vueuse/vueuse`（22,391 ★，MIT）

参考 `packages/core/useUrlSearchParams/index.ts`（VueUse 官方组合式函数，非框架文档）：

- **设计**：把 `URLSearchParams` 映射为响应式对象；写入时过滤空值（`removeNullishValues` 默认 `true`），因此默认值不会污染地址。
- **历史策略**：写回默认 `replace`，只有显式需要时才 `push`；`popstate` 只把地址读回状态，不再写历史。
- **防回环**：写入前 `pause()` 监听器，`nextTick` 后 `resume()`，避免“状态 → URL → 状态”循环。

**采纳**：默认值省略、筛选用 `replaceState`、popstate 反向同步、写入期间不重复触发。
**未采纳**：把整个查询串做成响应式对象——本项目要与 `#messages-*` 分区锚点共存，且需保留外部参数；继续使用白名单式 `writeRoute` 更可控（VueUse 的方案会重建整个查询串）。

### 1.2 样式分层：ITCSS（`BlazeSoftware/atoms` 1,551 ★；`ahmadajmi/awesome-itcss` 207 ★）

- **设计**：按“Settings → Tools → Generic → Elements → Objects → Components → Utilities”的倒三角组织，层次越靠下越具体，禁止跨层反向依赖。
- **收益**：新增页面只改对应层，减少“改一处、坏一片”的级联冲突。

**采纳**：本项目已有 14 个分区注释，直接按分区 1:1 拆文件，保持原有层叠顺序（令牌 → 基础 → 骨架 → 构件 → 页面 → 弹层 → 大字 → 响应式）。
**未采纳**：引入 Sass/Less 或 BEM 命名改造——会扩大改动面，且与“不新增依赖”约束冲突。

### 1.3 视觉回归：`mapbox/pixelmatch`（6,997 ★，ISC）

- **设计**：逐像素比较，使用 YIQ 色彩距离与可配置阈值，并检测抗锯齿像素以降低误报；输出差异图。
- **取舍**：项目处于离线环境且规定“不新增运行时依赖”，引入 `pixelmatch` + PNG 解码器会破坏该约束。改用**同机同浏览器字节比对**：两个入口均为纯本地渲染、无外部字体/图片，连续两次截图已验证哈希一致（见 §3.3）。代价是浏览器升级后需重建基线，已在文档与脚本中写明。

### 1.4 官方文档核对

- **MDN History API**：`pushState`/`replaceState` 不触发 `popstate`，`popstate` 只在前进/后退时触发——现有 `routeSignature` 去重逻辑与此一致。
- **Vue 3 文档**：`<script setup>` 的 `defineEmits` 类型声明用于筛选事件；未使用实验性 API。
- **Vite 文档**：CSS `@import` 会在构建时内联，顺序即层叠顺序——因此 14 个分层文件必须按原顺序导入。

### 2.2 可分享的社区筛选（新功能）

**URL 约定**（补充到 `docs/深链与历史导航-2026-10-23.md` §3.4）：

| 参数 | 取值 | 行为 |
|---|---|---|
| `filter` | `help` / `volunteer` / `neighbor` | `all` 省略；仅社区页生效 |

- **写入**：点选筛选调用 `writeRoute(..., { replace: true })`，不产生历史记录；刷新、复制地址仍可还原。
- **校验**：只接受三个白名单值，未知值在首次加载时 `replaceState` 清除并提示“链接中的筛选条件不存在，已显示全部动态。”
- **短链归一**：只有 `?filter=` 的地址会补上 `tab=community`，让地址自解释。
- **复制视图链接**：结果行右侧新增按钮，调用 `buildShareUrl({ tab, filter })`，只含页签与筛选，**不含搜索词、演练身份、“只看待接单”**。
- **无障碍**：`role=status` 的实时区只包住“当前显示 N 条动态”，复制按钮放在实时区外，避免每次筛选都播报“复制视图链接”；窄屏按钮高度 44px。

改动文件：`src/community/App.vue`、`views/CommunityView.vue`、`styles/04-components.css`、`styles/14-responsive.css`。

### 2.3 视觉回归基线（P2.4）

新增 `tools/check-visual.mjs`：

- 7 个固定状态：B 首页/社区/发布（1440）、我的/首页（390），A+ 队列（1440/390）。
- 每个状态固定 localStorage、身份、页签与等待时间；截图后计算 SHA-256，与 `tools/visual-baseline/*.png` 比对。
- 失败时把实际图写入 `docs/运营准备/evidence-visual-regression/<id>.actual.png`，并输出 JSON 运行记录。
- `--update` 重建基线；浏览器版本写入记录，升级 Chrome 后应重修基线。

```bash
node tools/check-visual.mjs            # 7/7
node tools/check-visual.mjs --update   # 有意的视觉变更后重建
```

## 4. 已知限制

1. 视觉基线是**同机同浏览器**字节比对：换机器、换 Chrome 版本、系统缩放变化都会导致整批失败；此时先人工核对再用 `--update`。
2. `filter` 只覆盖社区四类动态；搜索词、身份、“只看待接单”仍不入 URL。
3. 样式拆分只改文件组织，不改选择器与令牌；`src/App.vue`（1,923 行）仍未拆分（P2.1）。
4. 未做真实浏览器前进/后退、读屏器、200% 缩放的人工验收，P0 发布门禁不变。
5. 未执行 Git 提交/推送与部署。
