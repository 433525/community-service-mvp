## 7. 下一轮落地路线（UI / 可访问性 / 文案）

### 第 1 步：定 token（半天，零依赖）

1. 从 Vant 借命名（`--van-primary-color` / `--van-text-color` / `--van-background` / `--van-padding-*` 已本地确认），在 `src/style.css` 的 `:root` 建一层别名；
2. 从 Open Props 只 vendor `colors.css` / `sizes.css` / `easings.css` 到 `src/assets/tokens.css`，与上一步做显式映射（只留一套语义）；

**验收**：`src` 中不再出现新的裸数值（`13px`、`#8a8a8a` 这类），全部走变量。

### 第 2 步：可访问性闸门（1 天）

按顺序做，每条都能勾：

1. `src/App.vue` 顶部加 skip link + 路由/视图切换回焦（D4 方案）；
2. 所有图标按钮补 `aria-label`（E2 规则），装饰图标 `aria-hidden="true"`；
3. 表单 `label for` / `id` 显式绑定，错误用 `aria-describedby` 关联，错误提示不只靠颜色；
4. 弹层按 dialog 契约验：`Esc` 关闭、焦点圈闭、关闭回焦（C3）；
5. 动效逐条加 `prefers-reduced-motion` 分支（现状：全库仅 2 处，是全项目最薄的一环）；
6. 断点自测 320 / 375 / 414 / 768：无横向滚动、按钮不折行、图片有宽高（E3 baseline-ui §4–§6）。

**验收**：E2 的 `command.md` 规则逐条过一遍，只留 `✓ pass` 与明确豁免项。

### 第 3 步：文案（半天）

1. 按 E1 的“动作名一致”，把按钮 / 提示 / 空态 / 错误四类文案拉一张表对齐；
2. 按 E5 删：三连排比、破折号连接、“不只是…而是…”、AI 高频词（赋能、无缝、一站式、深度）；
3. 按 C2 的 “Use plain language” 把审核规则、举报说明改到初中阅读水平。

**验收**：每个 CTA 都能回答“点了会发生什么”；每个错误提示都含“原因 + 下一步”。
