## 6. 对比度抽样（计算样式 + 手算公式）

方法：用 `getComputedStyle` 读取前景色、逐级合成祖先背景色到不透明背景；按 WCAG 2.x sRGB 相对亮度公式计算：

```text
L = 0.2126 R' + 0.7152 G' + 0.0722 B'
对比度 = (L_light + 0.05) / (L_dark + 0.05)
```
