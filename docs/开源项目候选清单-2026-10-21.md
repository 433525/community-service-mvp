## 1. 先看本项目前端的 7 个缺口（只读源码证据）

这一节只列与本清单直接相关的现状，不重复 README 的功能说明。

1. **弹窗实现重复，焦点陷阱是手写的。**
   `src/App.vue:444-489` 用 `dialogFocusables()` + `watch(anyDialogOpen)` 做首焦点、Tab 循环、Esc 与焦点归还；A+ 端有 9 个 `role="dialog"`（`src/App.vue:1495-1760`），社区端帮助弹层在 `src/community/App.vue:54-94` / `:208-225`，首页安全弹层在 `src/community/views/HomeView.vue:146`。逻辑可用，但**背景没有 `inert` / `aria-hidden`**，只靠 `aria-modal="true"`；破坏性操作（恢复/覆盖存档）用的是 Vant `showConfirmDialog`（`ProfileView.vue:185-193`），不是 `alertdialog` 语义。

2. **skip link 已有，但“切页后焦点回主内容”没有统一处理。**
   A+ 在 `src/App.vue:1143`、社区在 `src/community/App.vue:129` 都有 `跳到主内容`，目标 `#aplus-main` / `#community-main` 带 `tabindex="-1"`；但 `navigateTab()`（`community/App.vue:110-117`）只改 `activeTab`，未发现把焦点移到 `main`/`h1` 的代码。**未做浏览器实测**，标记为“代码检索结论”。

3. **live region 是零散的，不是统一的 announcer。**
   社区 toast 在 `community/App.vue:225` 用 `role="status" aria-live="polite"`；“我的 → 服务记录”在 `ProfileView.vue:274` 用 `aria-live="polite"`；A+ 的存储状态、暂停状态、桥接状态分别在 `App.vue:1212`、`:1223`、`:1534`；表单错误用 `role="alert"`（`PublishView.vue:165`）。语义大体正确，但**没有统一的 polite/assertive 队列、超时清理与重复消息抑制**。

4. **设计 token 只有颜色，字号与对比度是硬伤。**
   `src/style.css:1-23` 只定义了 15 个颜色/阴影变量，没有间距、字号、行高、缓动阶梯；`community/style.css` 中 grep 到约 180 处 `font-size: 7–11px`（含移动端覆盖），例如 `:34` 10px、`:60` 9px、`:105` 8px、`:312` 7px。按 CSS 颜色值手算 WCAG 对比度（不含透明度/抗锯齿）：
   - `#89948c` on `#fffefa` = **3.12:1**（社区 muted 10px，低于普通小字 4.5:1）
   - `#9aa49b` on `#fffefa` = **2.55:1**（8px 三级文字）
   - `#737e76` on `#fffefa` = **4.18:1**（社区正文 10px，仍低于 4.5:1）
   - 对照：A+ `#5e7076` on `#fff` = **5.18:1**，项目 teal `#176c69` on `#fff` = **6.20:1**。
   Vant 的 `--van-gray-6`（`#969799`）on white 只有 **2.92:1**，**不能直接拿来做小字**。

5. **存储与备份是现有资产，不应被通用库替换。**
   `src/community/storage.ts` 固定 key + schema version；`community/store.ts` 有写入失败回滚、多标签冲突、坏档保护；`domain/intake-backup.ts:22-24` 限制 5MB / 1,000 条，`:273` 起逐字段校验并保留 v1 兼容。通用 `useStorage` / localForage 无法自动继承这些语义。

6. **状态机是手写 guard，不是单一转移表。**
   社区订单状态：`open → accepted-local-demo → completion-requested → completed-local-demo`，另有 `cancelled-local-demo`、`disputed-local-demo` 与撤销争议回 `accepted-local-demo`（`community/store.ts:1229-1566`）；A+ 另有 11 个受理状态（`domain/intake.ts:29-56`）。每条路径都有 `if` 校验，但**没有一张可被测试直接枚举的“状态 × 事件 × guard”表**。

7. **可访问性验收是自研 CDP 脚本，不是标准工具链。**
   `tools/audit-a11y.mjs:1-12` 明确是“zero-dependency CDP helper”，文件 1,516 行，覆盖焦点行为、ARIA、标签、移动布局、触控目标、计算色值；`package.json` 没有 Playwright/axe/Lighthouse 依赖，也没有 test script。自研脚本很贴合本项目，但**规则广度与跨版本可比性**不如 axe/Lighthouse。

### C1 · Vant 4（youzan/vant）— 91/100 — **adopt（深化现有依赖）**

- **URL**：<https://github.com/youzan/vant> ・文档 <https://vant.pro/vant/>
- **License**：MIT（GitHub API `license.spdx_id=MIT`；npm `vant@4.10.2` `license: MIT`）`[已核实]`
- **最近更新**：push `2026-10-20`；最新 release `v4.10.2`（`2026-08-31`）`[已核实]`
- **Stars**：24,395（约 2.44 万，2026-10-21 快照）`[已核实]`
- **技术栈**：Vue 3/2、TypeScript、CSS 变量 + Less；README 称“1KB average component、80+ components、zero third-party dependencies、tree shaking、custom theme、accessibility (still improving)”。
- **对应本项目**：`src/community/views/ProfileView.vue:3` 的 `showConfirmDialog`；`src/community/main.ts` 手工引入 `css-variables/normalize/base/animation + overlay/popup/button/dialog` 六类 CSS；`src/community/views/PublishView.vue:150-165` 的表单；`CommunityView.vue:43`、`ProfileView.vue:262-324` 的空状态；`src/style.css` 与 `community/style.css` 的字号/间距。

  1. **已经是运行时依赖**，不需要新增库、不需要重新评估许可证；现有 `--van-*` 变量其实已在页面生效，只是组件层几乎没用。
  2. 官方 `css-variables.less` 直接给出本项目最缺的**间距/字号/行高/时长/圆角**阶梯，且全部是 CSS 变量，可以只借 token 不借组件。
  3. Form 的 `rules`（`required`/`pattern`/`validator`/`trigger`）与 Empty 的**内联 SVG**（无外部图片）正好对应发布表单和空状态两个高频界面。
- **可借鉴（1–2 点）**：
  1. **Token 阶梯**：把 `--van-padding-base:4px`、`xs:8`、`sm:12`、`md:16`、`lg:24`、`xl:32`，以及 `--van-font-size-xs:10px`、`sm:12`、`md:14`、`lg:16`、`--van-line-height-xs/sm/md/lg` 映射成自有的 `--space-1..6`、`--text-xs..lg`、`--leading-*`；先把社区 7–11px 的正文/说明抬到 12–14px，再谈 16px 正文。
  2. **Form + Empty**：发布表单可借 `rules` 的字段级校验与 `trigger`（`onBlur` 默认、可 `onChange`/`onSubmit`）；空状态可借 Empty 的“插图 + 描述 + 底部 CTA”结构，但**自己画/内联 SVG**，不要引 `@vant/assets` 的 CDN 图。
- **建议**：**adopt**。保留 Vant 依赖，但只扩到 token、Form、Empty 三处；不要因为“已经装了”就全面换装 Vant 组件，现有 68KB 手写样式与 Vant 默认观感会冲突。
- **风险 / 边界**：① Vant README 只说 accessibility“still improving”，**不是合规保证**；`showConfirmDialog` 的背景 `aria-hidden`/焦点行为未实测。② `--van-gray-6` 2.92:1，不能用于小字。③ 目前是逐文件手工 import CSS，新增组件必须同步补 CSS，否则样式缺失。
- **取证**：README（features）、`packages/vant/src/style/css-variables.less`、`packages/vant/src/form/README.md`、`packages/vant/src/empty/README.md`、`Empty.tsx`（内联 SVG）、npm registry。

- **关联度 84 的理由**：

  3. 体积极小、无样式，不会与 Vant/现有 CSS 冲突；但它是原生 DOM API，不是 Vue 组件。

  2. **可聚焦元素过滤**：按 `disabled`、`hidden`、`getClientRects().length`、`visibility` 过滤；处理 Shift+Tab 与“焦点跑到弹窗外”的兜底；打开时聚焦第一个**有意义**的控件，而不是关闭按钮。
- **建议**：**borrow-only**。不建议直接引入 vanilla 库再包一层 Vue；把上述行为补进现有 `dialogFocusables()`/`watch` 更划算。若未来弹窗继续增加，再考虑抽成 `useDialogFocus()` composable。

   以 Vant 的 `--van-padding-*` / `--van-font-size-*` / `--van-line-height-*` 为骨架，映射到 `:root` 的 `--space-*` / `--text-*` / `--leading-*`；从 Open Props 只抄 `--size-fluid-*`、`--ease-*` 各 3–5 个。先把社区 `7–11px` 的正文/说明抬到 `12–14px`，输入控件 ≥16px；对比度 <4.5:1 的 muted/tertiary 颜色换深一档。

2. **第 2 步（1 天）：把弹窗行为收口到一个 composable。**
   以现有 `src/App.vue:444-489` 为基础，抽 `useDialogFocus()`：首焦点、Tab 循环、Esc、归还焦点、背景 `inert`/`aria-hidden`；参考 a11y-dialog 的 APG 清单与 Reka UI 的 Title/Description。破坏性确认改用 `alertdialog` 语义，默认焦点给“取消”。先只改 1 个弹窗做对照，再铺到 11 处。

3. **第 3 步（半天）：统一 live region。**
   引入 VueUse `useLiveAnnouncer`（或照 40 行手写）：toast/草稿恢复走 polite，表单错误/存储失败走 assertive；同一消息 2–3 秒去重。补“切 tab 后焦点移到 `main`/`h1`”的统一逻辑，让 skip link 的承诺在 SPA 内也成立。

4. **第 4 步（1–2 天，borrow-only）：给备份与订单补“可测试的模型”。**
   Zod 只写并行 schema 做测试 oracle，先比对现有导出样本的接受/拒绝结果；XState 只画订单状态表 + 表驱动测试，不引运行时。目标是让“非法转移/坏档”有可枚举的用例，而不是换库。

5. **第 5 步（半天，评估）：a11y 闸门对照。**
   用 @axe-core/playwright 对 6 个状态跑一次（首屏、弹层打开、表单报错、大字模式、空状态、存档错误），与 `tools/audit-a11y.mjs` 结果合并；本地跑一次 LHCI 存基线。**不提交依赖、不上传报告**，先看误报与漏报。

6. **动效（可选，最后做）：只取 1 个 CSS 转场。**
   在 transition.css 许可证澄清前，不 vendor；手写 20 行 `wipe/fade`，时长 180–260ms，保留 `prefers-reduced-motion` 1ms 降级。只用于 tab 内容切换或 toast，不用于关键状态/表单。

### 4.3 方法说明

- GitHub 网页在 21:00 后出现 `resolves to a non-public IP address`，`web_fetch` 无法继续抓 `github.com` / `api.github.com`；仓库元数据改用本机 PowerShell 对**公开 REST API** 的只读 GET（未克隆、未安装、未运行仓库代码）。README/官方文档优先用 raw 内容与官网；Vant/VueUse 的 SPA 文档页只作为导航，具体结论取仓库内 markdown/less 源文件。
- 对比度按 CSS 声明的 sRGB 值计算 `(L1+0.05)/(L2+0.05)`，未计透明度叠加、渐变、图片背景、抗锯齿与实际渲染；阈值按普通小字 4.5:1、非文本/焦点 3:1 参考。

## 7. 一句话总结
