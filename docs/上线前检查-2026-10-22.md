## I. 养护与更新说明

### I1. 日常改动流程
1. 改代码前先跑一遍门禁，确认基线为 **119/119**。
2. 只改 `src/` 内的实现；不要改 `tools/check-*.mjs` 的既有期望（除非同步更新交付文档中的基线说明）。
3. `npm run build` → `npm run preview -- --host 127.0.0.1 --port 5180 --strictPort`。
4. 串行跑 14 个脚本（含 `check-ui-hardening`）+ `audit-ui` + `probe-errors`。
5. 把新的构建哈希写入 `docs/交付-2026-10-21-产品级重构.md` §4.1。

### I2. 常见改动落点
| 需求 | 文件 |
| --- | --- |
| 改配色/字号/间距 | `src/style.css`、`src/community/style.css` 顶部令牌区 |
| 新增页签 | `src/community/App.vue` 的 `tabs` + `views/` 新视图 + 移动底栏 |

| 改无障碍 | 同步 `tools/audit-ui.mjs` 与 `tools/check-ui-hardening.mjs` |
