## 1. 项目背景与目标

- **项目性质**：学校大创项目的本地原型，不是可接入真实运营的系统。
- **两个入口**（同一个静态站、同一套共享能力，数据各自独立）：
  - `/`：A+ 受控登记工作台，面向受理席/复核席/转介席，演练「登记 → 初筛 → 待补充 → 分诊 → 转介 → 跟进」。
  - `/community.html`：B 受控社区，面向居民/志愿者/审核员，演练「发布 → 审核 → 接单 → 履约 → 留言 → 举报 → 反馈」。
- **核心价值**：把社区求助从「发帖」到「内部受理」的链路做成可演示、可验收的闭环；所有数据为合成数据，只存在当前浏览器。
- **明确不做**：真实居民数据、真实账号/权限、后端/数据库、真实通知/结算、公开上线（在 G3 阻塞项关闭前）。
- **当前阶段**：Phase 3/4 收尾。功能完整，静态可部署性已就绪；公开发布门禁未通过。

## 5. 已完成的功能与模块

### 5.1 A+ 工作台

- 队列：筛选、搜索、计数、逾期/高风险标记、桌面吸顶 + 面板头吸顶、移动端主从跳转与返回。
- 记录：新建、初筛、待补充、已提供信息、待分诊、转介、跟进、检查点、高风险停止/人工交接、关联记录。
- 角色：受理席/复核席/转介席（仅展示，不是权限），角色写入时间线。
- 重复候选：完全重复时暂停创建，需人工复核说明。
- 投诉复核：独立队列、独立存档、不改写风险或跟进；页头有直达入口与待复核计数。
- 存档：导出 JSON、导入校验、坏档下载原文、重置、写入失败回滚、多标签冲突检测。
- 社区桥：单向读取 B 审核通过的求助，按来源帖去重，不写回社区。
- 说明弹层：6 个分区 + 推荐演示顺序；焦点闭环、Esc、背景 inert。
- 打印：只打印当前记录详情（打印抬头、隐藏队列/顶栏/按钮）。
- 桌面 ≥1021px：队列 sticky；移动端：选中后滚入详情并聚焦。

### 5.2 B 受控社区

- 身份：访客/已核验成员/审核员；访客看不到正文；切换无认证能力。
- 发布/评论：先审后发；本人可见审核状态与意见；草稿自动保存（确认勾选不恢复）。
- 求助订单：待接单 → 已接单 → 待确认完成 → 已完成；可取消/关闭/争议；每步写事件时间线；单订单 100 条事件上限。
- 时间账本/体验记录：完成生成“未结算”演示时长；1–5 星体验只存本机。
- 活动报名：仅活动招募可报名/取消。
- 消息：系统通知、按类型筛选、已读游标、全部已读、订单留言只读规则。
- 举报与审核：帖子/评论/留言举报；去重；四类筛选 + 跨类搜索；审核日志；下架不删原文。
- 我的：发布、收藏、求助、服务记录、活动、时间账本、存档只读快照。
- 大字模式、帮助弹层、安全弹层；分区导航滚动高亮；页签级按需加载。

### 5.3 共享与工程

- 设计令牌：`--fs-*`、`--sp-*`、`--r-*`、`--tap: 44px`、`--topbar-h`；A+ 正文 14px、B 正文 16px。
- 无障碍：对比度 ≥4.5:1、390px 触控 ≥44、Tabs 方向键、弹层焦点闭环、`aria-current`、`role=status/alert`、开关 `role=switch`、强制配色。

## 9. 代码规范与约定

1. **样式分层**：令牌 → 基础 → 骨架 → 通用构件 → 页面 → 弹层 → 响应式；B 端已按此拆到 `src/community/styles/`，新增页面样式放对应文件，不复制粘贴。颜色/字号/间距优先用令牌，不在组件里堆十六进制。
2. **两套主题**：A+ 深青+冷灰，B 暖米+草绿；不要互相串色。
3. **顶栏高度**：统一 `--topbar-h`（68/60/76px），凡 `position: sticky` 的导航必须引用它。
4. **长页分区**：用 `.section-jump` + `useSectionSpy()`；容器需 `display:flex; flex-direction:column`，否则 grid 行高会限制 sticky。
5. **页签分包**：新增 B 页签必须走 `asyncView()`，并补 loading/error 兜底；不要直接静态 import 进 `App.vue`。
6. **弹层契约**：`role=dialog` + `aria-modal` + `aria-labelledby/describedby`；焦点优先 `[data-autofocus]` → 首个字段 → 首个可聚焦；Esc 关闭并归还焦点；背景 `inert`。
7. **筛选组**：用 `v-tablist`，`role=tab` + `aria-selected`，支持 ←/→/Home/End。
8. **状态播报**：结果计数 `role=status aria-live=polite`；错误 `role=alert aria-live=assertive`。
9. **存储**：所有读写经 `storage.ts` / store；结构变更必须写迁移与坏档恢复；不要直接 `localStorage.setItem` 绕过保护。
10. **可访问性**：对比度 ≥4.5:1（大字 ≥3:1）；390px 触控 ≥44×44；焦点可见；不要用颜色单独传达状态。
11. **不引外部资源**：字体、图标、CDN、统计脚本一律不加；`noindex` 与根路径部署前提不要破坏。
12. **语言**：界面文案中文；代码注释中文/英文均可，但解释“为什么”而不是“做了什么”。
13. **测试基线**：不要为了通过而改既有断言；确需改基线（设计升级），必须同步更新交付文档中的说明与计数。
